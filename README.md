# Library Management System (Java)

A console-based Library Management System built using Java and Object-Oriented Programming principles.

## Features

- Add Books
- View Books
- Search Books
- Update Books
- Delete Books

## Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- ArrayList
- Loops
- Switch Statements
- Scanner Input
- CRUD Operations

## Technologies

- Java
- IntelliJ IDEA
- Git
- GitHub
